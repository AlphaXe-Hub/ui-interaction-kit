给 AI 编码助手的交互选型知识库：92 个词条，选对一个再写代码

UI Interaction Kit 把「有质感」「跟手」「像液体」「更高级」这类模糊的动效需求，翻译成 92 个已定义的交互词条 （interaction patterns / motion textures），让 AI 编码助手在动手前先选对一个主交互，再按明确的规则实现。 它不是组件库，也不绑定框架：每个词条都写清了触发方式、开始状态、变化过程、结束状态、取消状态，可直接用于网页、原生 App 与小程序。

本页是这 92 个词条的可运行 Demo（纯原生 JavaScript，零依赖），支持深色 / 浅色主题与减少动效降级。 滚动驱动的三个模式另有独立的完整示例页 scroll.html（该页的全息扫描段使用 Three.js WebGL，加载失败会降级为静态示意）。 Skill 本体可安装到 CodeBuddy、Claude Code、Cursor 等支持 SKILL.md 的 AI 编码工具。

UI Interaction Kit: 92 front-end interaction patterns — pick the right one before writing code

UI Interaction Kit turns vague motion requests — "make it feel snappier", "follow my finger", "like liquid" — into 92 well-defined interaction patterns (motion textures, chart interactions, app patterns, overlays, loading states, scroll-driven scenes, texture components, gesture feedback, icon micro-interactions, instant feedback components), so an AI coding assistant chooses one primary interaction before touching the code. It is not a component library and it is framework-agnostic: every entry documents its trigger, start state, motion, end state and cancel state, and applies to the web, native apps and mini programs alike.

This page is the runnable demo for all 92 entries (vanilla JavaScript, zero dependencies) with dark / light themes and a reduced-motion fallback. The Skill itself installs into CodeBuddy, Claude Code, Cursor and any other AI coding tool that supports SKILL.md. The three scroll-driven patterns have their own full-length example page, scroll.html (its hologram-scan section uses Three.js WebGL and falls back to a static drawing if that fails to load).
