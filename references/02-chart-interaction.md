# 02 图表交互｜7 种 Chart Interaction

在开发或维护含图表的页面时，先结合上下文分析页面、图表、数据结构与用户任务，从 7 种交互中判断最合适的一种，解释决策依据并用现有技术栈实现。

**顺序：先理解任务，再选择交互，最后编写代码（Understand the task first. Choose the interaction second. Code third.）。**

## 决策顺序

1. **看数据**：时间跨度多大？系列有几个？数据点数多少？是否有层级（汇总 → 明细）？
2. **看任务**：用户是想比较、定位、读值、筛选还是深入？
3. **看设备**：桌面有悬停与滚轮，移动端需要触控友好的替代方案（长按、双指、按钮）。
4. **选一种**：默认只加一种主交互。已有交互能满足就不新增。

## 选型表

| 交互类型 | 适用场景 | 触发方式 | 视觉反馈 |
|---|---|---|---|
| Brush Selection 框选 | 用户需要选择特定的时间范围或数据范围 | 在图表上横向拖动 | 半透明选区 + 选区外降饱和 + 边界手柄 |
| Crosshair 十字线 | 用户需要对齐数据点并查看对应的数值 | 悬停 / 长按拖动 | 垂直+水平参考线，轴上显示对应刻度值 |
| Data Point Highlight 数据点高亮 | 用户需要强调某个特定或重要的数据点 | 数据条件触发 / 悬停 / 点击 | 点放大、加描边或脉冲，其余点降级 |
| Tooltip 数据提示框 | 用户需要查看某个特定数据点的详细信息 | 悬停 / 点击 / 长按 | 跟随点的浮层，含标题、数值、单位、对比 |
| Legend Filter 图例筛选 | 用户需要显示、隐藏或比较不同数据系列 | 点击图例项 | 系列淡出/淡入，图例置灰，坐标轴重算 |
| Zoom 图表缩放 | 图表覆盖较大范围，需要查看局部趋势 | 滚轮 / 双指 / 框选 / 拖动滑块 | X 轴重刻度，提供重置入口 |
| Drill Down 数据下钻 | 用户需要从汇总数据进入更详细的数据层级 | 点击数据元素 | 图表替换为下一层数据 + 面包屑返回 |

## 选择依据（写进交付说明）

- 用户试图完成什么；
- 推荐哪种交互；
- 为什么其他交互不适合（例如：只要读一个点的详情就不需要框选；只有一条系列就不需要图例筛选）；
- 应如何被触发；
- 应提供什么视觉反馈；
- 桌面端与移动端是否需要不同的交互。

## 实现要点

- **不要为了视觉堆叠多种交互**，不要改变现有数据的含义（例如筛选不等于修改源数据）。
- 不要改变数值轴含义：图例筛选隐藏系列后，若 Y 轴自适应需明确告知，避免误读。
- 移动端替代方案：框选 → 双指或范围按钮；悬停提示 → 点击/长按；滚轮缩放 → 双指 + 缩放按钮。
- 缩放必须提供重置入口与当前区间提示；下钻必须提供面包屑或返回。
- 大数据量时用节流 / rAF 合并更新，避免每次指针移动重排整个图表。
- 键盘可达：图表容器可聚焦，方向键移动当前数据点，Enter 触发提示或下钻。
- 遵循 `prefers-reduced-motion`：去掉过渡动画，保留即时状态切换。
- 当前情况不需要图表交互时，明确说明原因（例如静态插图型小图、仅作装饰的迷你图）。

## 各交互的验收

| 交互 | 验收点 |
|---|---|
| 框选 | 拖动即时跟随、可反向、松手后区间正确、可清除；区间外仍可辨识 |
| 十字线 | 线不抖动、轴上数值与最近点对齐、离开图表即消失 |
| 数据点高亮 | 高亮点不遮挡邻近点、不与 tooltip 冲突、条件变化时更新 |
| 提示框 | 不越出容器、靠近边缘翻转、内容更新无闪烁、触摸可用 |
| 图例筛选 | 至少保留一条系列的可用状态；全部隐藏时给出空状态说明 |
| 缩放 | 有最小/最大层级、可重置、缩放后标签不重叠 |
| 下钻 | 层级路径清晰、可逐级返回、返回后滚动与选择状态保持 |

## 典型反例

- 只有 5 个数据点的柱图加缩放 —— 无意义，缩放层级比数据点还多。
- 单系列折线图加图例筛选 —— 没有可筛选的对象。
- 同时加十字线、提示框、数据点高亮并让三者各自重绘 —— 属于堆叠，应合并为一次指针事件驱动。
