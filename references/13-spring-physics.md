# 弹簧物理｜Spring Physics

> 适用场景：需要**可中断、可接续、手感自然**的运动——按压回弹、拖拽释放、抽屉进出、气泡弹出、跟随追踪。
> 这一篇不讲"某个效果怎么做"，讲的是**什么时候该用弹簧、三个参数怎么选、以及弹簧相对固定时长缓动的真实差别**。

## 一、什么时候该用弹簧，什么时候不该

弹簧不是"更好的 easing"，它是**另一种控制模型**：easing 描述"在固定时长内怎么走完这条路"，弹簧描述"被一个力拉着往目标去"。

| 情况 | 用弹簧 | 用固定时长 easing |
|---|---|---|
| 动画可能被打断（连点、换向、拖动中改目标） | ✅ 保留速度，自然接续 | ❌ 中断处速度归零，会有"顿一下" |
| 需要明确的起止时间（序列编排、stagger） | ❌ 收敛时间不确定 | ✅ 时长可预测 |
| 跟随连续输入的指针／滚动位置 | ✅ 阻尼追随 | ❌ 每次输入重置过渡，明显滞后 |
| 纯透明度淡入淡出 | 一般不必 | ✅ 更可控 |
| 进度条、可计算的进度 | ❌ | ✅ 时长/位置由进度决定 |
| 需要"匀速"或强节奏（如打字机） | ❌ | ✅ |
| 越界回弹、抛掷惯性 | ✅ 天然表达 | ❌ 要硬写关键帧 |

一句话：**会被人反复打断的、跟手的、需要"惯性"的 → 弹簧；一次性、可预测、需要精确编排的 → easing。**

## 二、三个参数是什么

- **stiffness（k，刚度）**：拉得有多硬。越大越快到位，也越"冲"。
- **damping（c，阻尼）**：摩擦。越大越早停止振荡；太小会来回弹很久。
- **mass（m，质量）**：惯性。越大启动越"重"、转向越迟缓。

三者的关系可以用**阻尼比**统一描述：

```
ζ = c / (2 × √(k × m))
```

| ζ | 名称 | 表现 |
|---|---|---|
| ζ < 1 | 欠阻尼 | 会越过目标再回摆，弹感强（ζ 越小弹得越久） |
| ζ = 1 | 临界阻尼 | 最快到达且不过冲，最"干脆" |
| ζ > 1 | 过阻尼 | 不过冲但更慢，稳重、迟钝 |

**注意：调这三个参数不要凭手感乱试**——先想清楚"要不要过冲"（决定 ζ 落在哪个区间），再定"多快"（决定 k），最后用 m 调"分量感"。同样想要弹一下，把 k 调大 4 倍和把 c 调小一半，观感是不一样的：前者更快更紧，后者更飘更久。

### 场景起点（都是设计选择，必须按项目调）

| 场景 | stiffness | damping | mass | 大致 ζ | 期望观感 |
|---|---|---|---|---|---|

## 三、实现要点

1. **按时间步长积分，不是按时长播放。** 每帧用真实 `dt`（并 clamp 掉长帧，比如 `min(dt, 0.05)`），这样在 60Hz 和 120Hz 设备上手感一致。
   ```js
   const a = ((target - value) * stiffness - velocity * damping) / mass;
   velocity += a * dt;
   value += velocity * dt;
   ```
2. **必须收敛并停止。** 判定 `|value - target| < ε 且 |velocity| < ε`，然后停止 rAF、把值钉到目标。否则会永远跑着一个几乎看不见的循环。
3. **不要和 CSS transition 混用。** 同一个属性既被 transition 管、又被逐帧写值，会互相打架。弹簧驱动的属性请把 `transition` 设为 `none`。
4. **只驱动合成属性**（`transform`、`opacity`）；不要每帧改 `width/height/top/left`，也不要每帧读布局（`getBoundingClientRect` 之类）造成强制重排。
5. **中断靠改目标实现，不要重启动画。** 用户中途反向时，只把 `target` 换成新值，**保留当前 `value` 和 `velocity`**——这正是弹簧比 easing 强的地方。
6. **`prefers-reduced-motion` 直接跳到目标**（`value = target; velocity = 0`），保留功能不留运动。
7. **一次点击触发的动作，记得防重入**：连点时应改目标而不是叠加多个积分器。

## 四、四个必须讲清的状态

任何弹簧驱动的交互，在交付说明里都应写清：
1. **触发**：什么改变 `target`（点击 / 释放 / 数据变化）。
2. **参数**：`stiffness / damping / mass` 取值，以及是否期望过冲。
3. **中断行为**：动画中途再次触发时，是保留速度接续（推荐），还是重置。
4. **终态**：收敛判定的阈值、停止时机、值是否精确落在目标上。

## 五、验收清单

- 同一组参数在高低刷新率下观感一致（用 `dt` 积分而非固定步数）。
- 连续快速触发时，运动是**接续**的：不回到起点、不出现速度突变为 0 的顿挫。
- 收敛后 rAF 已停止，值精确等于目标（不是"接近"），没有残留的微小抖动。
- 中途反向、改变目标、松手取消都有确定结果。
- 不开 `transition` 混用；滚动／拖动过程中不触发强制重排。
- `prefers-reduced-motion` 下有即时到位的降级，功能不丢。
- 参数是调过的：过冲幅度、收敛时间符合该场景的期望，不是随手抄的一组值。
